# Rules from docs/prd.md

- R1 20 working days of leave per calendar year
- R2 request length counts working days only (Mon–Fri)
- R3 end on or after start, at least one working day, else 400 and nothing saved
- R4 only a manager approves or rejects; nobody decides their own request (403)
- R5 remaining = entitlement − approved working days in that year
- R6 only the requester cancels a pending request (403)
- R7 a request may not exceed the remaining balance (400)
- R8 employees see only their own requests; team list is manager-only (403)
- R9 a request stays inside one calendar year
- R10 only pending requests can be decided (409)
